## Merge result

The merge produced **14 conflicts**, all resolved with no unmerged index
entries remaining. The main decisions were:

- retained upstream's new contribution-driven Desktop shell and mounted
  Finance as a lazy full-workspace route instead of restoring the deleted
  legacy controller;
- retained upstream's lazy Web page architecture and the Finance page/API
  surface;
- combined upstream `a2a` default-off behavior with Finance's service-gated
  toolset and preserved Finance auto-enable when its service is configured;
- combined upstream dependency pins with local `klinecharts`; restored all 26
  cross-platform `@esbuild/*` lock entries plus Electron signing dependencies
  that macOS npm prunes;
- retained official API/session/MoA improvements alongside Finance endpoints,
  and preserved Finance translations plus the new upstream artifact strings;
- kept the local robust s6 download/checksum setup alongside upstream Docker
  changes.

The upstream merge does not modify tracked files under `trader/`. Finance's
execution, risk, portfolio and prediction authority therefore remain behind
the existing service/API boundary.
